### Clean-checkout type error that was fixed

The first clean-copy `npm run typecheck` failed with:

```text
app/layout.tsx(19,50): error TS2304: Cannot find name 'LayoutProps'.
```

Reason: `LayoutProps` is generated by Next.js route type generation, and a fresh
checkout has no `.next/types` or generated `next-env.d.ts` yet. The old
`typecheck` script ran only `tsc --noEmit`.

Fix: the script is now:

```json
"typecheck": "next typegen && tsc --noEmit"
```

After the fix, clean-copy typecheck passed. This is why the README tells
contributors to use `npm run typecheck` rather than calling `tsc` directly.

### Flaky concurrency test that was fixed

The first `npm test` in the clean copy was run concurrently with a production
build. The planner concurrency test failed:

```text
expected 1 to be 2
```

The fake model client used a 20 ms delay, so under CPU contention the first call
could finish before the second call reached the client. The test was timing
dependent, not a product concurrency bug.

Fix: the test now uses a gate. It holds the first two model calls open until both
have reached the fake client, then releases them. It still asserts that the
maximum number of active calls is exactly two. The test passed alone, in the full
suite, and in the clean copy.

## Safety checks covered by the suite

The automated tests exercise, among other things:

- path traversal and absolute destination rejection
- symbolic-link and junction refusal
- approved-root boundaries and filename sanitization
- read-only scanning and file manifests before/after a scan
- SHA-256 exact duplicates, same-size/different-content files, similar names,
  files changed during hashing, and unreadable files
- malformed, extra-field, wrong-extension, and misleading model replies
- prompt-injection text treated as untrusted data
- destination collisions and no silent overwrite
- partial failures and cancellation
- unapproved operations not being executable through the apply API
- history persistence, corrupt history records, and undo refusal conditions
- non-loopback Ollama URLs being refused before a prompt
- bounded text extraction for text, PDF, and DOCX files
